# Human Approval Gates

## HAG-1 Concept Approval

Approve concept, target users, use cases, item count, and language before style or production work.

## HAG-2 Rights and Risk Approval

Confirm no dependency on trademarks, copyrighted works, existing IP, public figures, unclear-rights material, advertising, or prohibited motifs.

## HAG-3 Style Lock Approval

Select and approve the fixed visual style from base candidates before batch production.

## HAG-4 Batch Plan Approval

Approve item list, expression spread, wording, and balance before mass generation or source-image finishing.

## HAG-5 Pre-ZIP Approval

Use `reports/validation.md`, `reports/contact_sheet.png`, and `submission_checklist.md` for final visual QA, readability, typo, and review-risk confirmation before manual LINE upload.

No agent may mark a project READY if required approvals are missing or validation has fatal errors.
